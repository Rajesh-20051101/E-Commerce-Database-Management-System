# E-Commerce Database Management System

## Project Overview
A MySQL-based project designed to manage e-commerce data,
including customers, products, orders, payments, and inventory.

## Technologies Used
- MySQL
- SQL

## Database Tables
- Customers
- Addresses
- Categories
- Brands
- Products
- Suppliers
- Inventory
- Orders
- Order Items
- Payments
- Shipments
- Reviews

## SQL Concepts
- Primary Keys and Foreign Keys
- Joins
- Aggregate Functions
- GROUP BY and HAVING
- Subqueries
- CTEs
- Window Functions
- CASE WHEN

## Project File
- project.sql: Database creation and sample data.
